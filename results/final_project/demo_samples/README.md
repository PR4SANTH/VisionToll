# VisionToll Demo Sample Set

All demo sample images are sourced strictly from the **validation split** (`data/processed/vision_toll_yolo/images/val`).
Zero test images are utilized in this demo sample set.

## Selected Representative Samples:

- **motorcycle_detection** (`demo_motorcycle_detection_1057.jpg`): Prominent motorcycle cluster with 3 motorcycles (Source: `val/1057.jpg`)
- **small_distant_vehicles** (`demo_small_distant_vehicles_1105.jpg`): Scene containing small distant vehicles (<32x32 pixels) (Source: `val/1105.jpg`)
- **crowded_scene** (`demo_crowded_scene_1152.jpg`): Crowded scene with 9 vehicles across classes: ['Car', 'Motorcycle', 'Auto Rickshaw'] (Source: `val/1152.jpg`)
- **multiclass_scene** (`demo_multiclass_scene_1181.jpg`): Multi-class scene with 4 distinct vehicle classes: ['Bus', 'Car', 'Motorcycle', 'Auto Rickshaw'] (Source: `val/1181.jpg`)
- **difficult_scene** (`demo_difficult_scene_1181.jpg`): Complex scene with Bus, Truck, and mixed traffic density (Source: `val/1181.jpg`)
